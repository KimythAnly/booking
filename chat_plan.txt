# Teacher Scheduler v1 - Project Specification

## Overview

Build a free web application for a single teacher to manage student lesson bookings.

### Requirements

* Only teacher-registered students can use the system.
* Students can request bookings.
* Students can request cancellations.
* Teacher must approve or reject booking requests.
* Teacher must approve or reject cancellation requests.
* Approved bookings automatically sync to Google Calendar.
* Approved cancellations automatically remove Google Calendar events.
* Teacher can create recurring weekly lessons.
* Entire solution should be free to host and maintain.

# Authentication

## Login Method

Use Google Sign-In.

Frontend obtains Google account email.

Frontend calls Apps Script:

```json
{
  "action": "validateUser",
  "email": "student@example.com"
}
```

Apps Script determines:

* Teacher
* Student
* Unauthorized

Response:

```json
{
  "role": "teacher"
}
```

or

```json
{
  "role": "student"
}
```

or

```json
{
  "role": "unauthorized"
}
```

# Google Calendar Integration

## Booking Approval

When a booking request is approved:

1. Create Google Calendar event.
2. Save event ID in Bookings sheet.
3. Update booking status.

Event title format:

```text
Lesson - Student Name
```

---

## Cancellation Approval

When a cancellation request is approved:

1. Find calendar_event_id.
2. Delete event from Google Calendar.
3. Update booking status to CANCELLED.

# Recurring Classes

Teacher can create:

* Student
* Weekday
* Start Time
* End Time
* Start Date
* End Date

Example:

```text
Student: Alice
Weekday: Friday
Time: 13:00-14:00
Start: 2026-09-01
End: 2026-12-31
```

System automatically generates lesson records and calendar events.

# Security Rules

* Only teacher email(s) may access admin routes.
* Only active students may access student routes.
* Frontend checks authorization.
* Apps Script must also validate authorization on every API request.
* Never trust frontend-only validation.

# Definition of Done

The project is complete when:

1. Teacher can add a student.
2. Student can login using Google account.
3. Student can request a booking.
4. Teacher can approve the booking.
5. Booking appears in Google Calendar.
6. Student can request cancellation.
7. Teacher can approve cancellation.
8. Calendar event is removed.
9. Teacher can create recurring weekly lessons.
10. System is deployed on GitHub Pages and fully functional without a dedicated backend server.
